Радиосигнал - электромагнитное колебание, которое может использоваться для передачи информации между устройствами.

Частота - количество полных колебаний сигнала за одну секунду. Измеряется в герцах (Гц).

Амплитуда - величина отклонения сигнала от нулевого уровня.

Шум - случайные колебания, которые накладываются на полезный сигнал и затрудняют его анализ.

Спектр сигнала - представление сигнала в частотной области, позволяющее определить присутствующие в нём частоты.

FFT (Fast Fourier Transform) - быстрое преобразование Фурье, позволяющее перейти от временного представления сигнала к частотному.


Для первоначального эксперимента используется синусоидальный сигнал частотой 50 Гц. Продолжительность сигнала составляет одну секунду, частота дискретизации - 1000 отсчётов в секунду.

Сигнал формируется по формуле:
x(t) = sin(2πft), где f - частота сигнала, t - время.
После генерации к нему добавляется случайный гауссовский шум со средним значением 0 и стандартным отклонением 0,5.
